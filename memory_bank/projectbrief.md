# Project Brief

## Overview

Исследование возможностей разработки приложений **под саму систему Huawei Band 10** (не companion на телефон).

Пример цели: калькулятор, который запускается на часах.

## Scope

- Исследовать технические характеристики Band 10 (железо, OS).
- Найти Huawei Lite OS SDK для разработки под носимые устройства.
- Определить, можно ли устанавливать сторонние приложения на Band 10.
- Создать первый прототип приложения (калькулятор).

## Project Deliverables

- [D1] Band 10 исследование (железо, OS, SDK) — completed — 40%
- [D2] Определение способа установки приложений — pending — 30%
- [D3] Прототип приложения (калькулятор) — pending — 30%
